# Mi Portfolio Personal - DAM

Hola Soy Juan López Lara, estudiante de 1º de **Desarrollo de Aplicaciones Multiplataforma** en el I.E.S. Gregorio Prieto.

## Sobre este proyecto
Este es mi primer portfolio desarrollado con **HTML5 semántico** y **CSS3**. 
El objetivo es poner en práctica lo aprendido en clase sobre:
- Estructura y etiquetas semánticas.
- Estilos externos con archivos CSS.
- Creación de formularios de contacto.
- Control de versiones con Git y GitHub.

## 🛠️ Tecnologías usadas
- HTML5
- CSS3
- Git / GitHub
